# AI幻觉致损 行动路线图

## 关键原则
**黄金24小时**：AI错误决策日志有保留期，越早索取越好。

## 路线图

```
第1天 ─ 书面《日志索取函》发出（EMS/邮件+回执）
第2-7天 ─ 等待机构答复（同时整理证据清单）
         ├─ 机构提供日志 → 分析幻觉证据 → 谈判赔偿
         └─ 机构拒绝/拖延
第8天 ─ 向12378/人民银行投诉（行政时限：15日内处理）
第15天 ─ 投诉无果 → 律师函 → 诉讼准备
第30天 ─ 起诉（管辖：被告所在地/合同履行地法院）
```

## 各环节要点

1. **日志索取函**：必须书面、必须留送达凭证（EMS回执/邮件回执）
2. **监管投诉**：12378热线或书面投诉，注意记录投诉编号
3. **诉讼**：可主张损失本金+利息+维权费用；申请法院调取日志（对方不配合=不利后果）

## 法律武器清单
- 《民法典》第1191条（单位责任）
- 《个人信息保护法》第24条（自动化决策透明度）
- 《消费者权益保护法》第55条（欺诈惩罚性赔偿，如适用）
- 《最高人民法院关于审理金融消费者权益保护纠纷案件的规定》（如有）
